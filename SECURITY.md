# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| main    | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in raghv.dev, please report it **privately** rather than opening a public issue.

**Contact:** raaghvv0508@gmail.com  
**Subject line:** `[SECURITY] raghv.dev — <short description>`

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Any suggested remediation (optional but appreciated)

I will acknowledge receipt within **48 hours** and aim to resolve confirmed issues within **7 days** for critical/high severity findings.

I will credit reporters in the fix commit unless you prefer to remain anonymous.

## Out of Scope

- Issues requiring physical access to my devices
- Social engineering attacks
- Denial-of-service attacks
- Issues in third-party dependencies (please report those upstream)
